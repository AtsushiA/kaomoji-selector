エディタ上で簡単に顔文字（kaomoji）を選び、記事に挿入できるブロックです。

== Description ==

このブロックを使うと、よく使われる顔文字一覧から好きなものを選択し、記事やページに簡単に挿入できます。使いやすいインターフェースで、編集と閲覧の両方に同じ顔文字が表示されます。

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/kaomoji-selector` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress
